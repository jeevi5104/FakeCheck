# FakeCheck - AI-Based Fake Information Verification

FakeCheck is a web application that helps users verify information using text and image verification.

## 🚀 Live Demo

https://fakecheck-1ap4.onrender.com

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- Tesseract OCR
- HTML
- CSS

## ✨ Features

- User Registration and Login
- Text Verification
- Image Verification using OCR
- Audio Verification
- Verification History
- Evidence Display
- User Profile
